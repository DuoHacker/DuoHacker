# Changelog

All notable changes to this project are documented here.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/). Versions use calendar versioning (`YYYY.MM.DD`), matching the userscript's `@version`.

## [Unreleased]

### Changed
- Reorganized the repository: `userscript/`, `extension/`, `desktop/`, `tools/generator/`, `docs/`.
- The userscript now lives at `userscript/duohacker.user.js` (previously `v2/duohacker-v2.user.js`). GreasyFork installs are not affected.
- Rewrote the README and community files (contributing guide, code of conduct, security policy, support page).

### Added
- Installation guide and FAQ in `docs/`.
- Issue templates, pull request template, `.editorconfig` and `.gitattributes`.
