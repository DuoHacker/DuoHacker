# DuoHacker Desktop

Electron app that opens Duolingo with the DuoHacker userscript injected.

## Download

Prebuilt Windows installer: [Download](https://drive.google.com/uc?export=download&id=1u_b5hNGM4qYcahuT7mr4fDHPS_4T_8Au)

## Build from source

```bash
cd desktop
npm install
npm start        # run locally
npm run build    # build the Windows installer into desktop/dist/
```
